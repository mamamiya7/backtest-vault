# Backtest Vault 0.20.0 — Community / Pro pilot candidate

Not published. Public checkout is off. The installed v0.19.0 source engine remains the accepted baseline.

Community retains every existing backtesting feature. New Pro tools add reusable, versioned research plans; sensitivity maps with matched conditions and saved-report links; and locally generated HTML research reports. Expiring signed pilot licenses activate those tools. Saved work remains available after expiry.

Full backups include research plans and exclude licenses. One Windows/Linux package serves both editions. A separate upload ZIP places the manifest at its root for a future Chrome Web Store item.

See [Edition details](EDITIONS.md) and [Distribution](DISTRIBUTION.md) for activation, licensing limits, migration and remaining launch gates. No new source scans, live trades, payment requests or cloud record uploads are introduced.
