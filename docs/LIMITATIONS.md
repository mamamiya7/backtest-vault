# Known limitations

- Preview release; not listed in the Chrome Web Store.
- Experiments includes a DOM runner, finite/sample/adaptive planner and durable journal. Version 0.19.0 extends automated execution to independent Candle, P&F and Renko main/exit charts under NSE and Price selection. Non-Price execution remains gated. Normal Candle tests were reported working by the user; the earlier v0.7.3 three-trial saved-baseline sweep was independently checked. Three-trial P&F and Renko batches plus a mixed P&F-entry/Renko-exit run passed installed, exported-record verification. Additional chart/filter combinations passed automated fixtures; this is not exhaustive live coverage. Relative Strength and Market Trend Filter preserve complete source readback and capture. Reading/editing choices and simulated tests do not prove installed automatic execution. See [Experiments](EXPERIMENTS.md).
- Dropdown metadata, Group, private Radar menus, keyword results and loaded filter symbols are retained in this browser profile for the local day across RZone reloads. Current inputs are read freshly and each trial verifies current source choices. Use Recheck all choices after switching RZone accounts or changing rules; this page exposes no stable account identifier. New structural contexts need their first lookup, and a new day or adapter version expires the cache. My/Public searches still require a keyword. Symbol fields expose source search matches, not a complete instrument catalogue. Search a more specific name if a broad query omits the required symbol; matching-market results and exact query receipts are reused for the day within bounded local storage.
- Date and portfolio sweeps are available through New test; the older saved-run route retains its existing numeric strategy ranges. Changing dates or portfolio assumptions creates separate comparison groups. Adaptive search uses the seeded pool order for these mixed-condition plans.
- The extension depends on Definedge's visible form and report structure. Future changes may require new adapters.
- STR and Exit Strategy My/Public expose keyword searches rather than complete blank-query dropdowns. Vault loads matching results on request; no matches does not prove the entire category is empty. Duplicate names cannot be selected automatically. Finish or clear an unverified source search before reconnecting; Vault cannot infer whether arbitrary text is a committed source rule.
- New connected setup currently supports NSE. BSE, MF and EQW remove Radar controls and require their own verified adapters; they remain visible as unavailable choices in fresh templates. Inspecting their menus does not establish automatic execution support.
- Five exported Candle runs have been checked against live references. The v0.19.0 P&F/Renko batches verify settings, fresh lifecycle, full capture and durable saves; they do not independently audit RZone calculations. RS and Market Trend Filter were off in those live batches.
- The dashboard and v0.4.0 strategy analysis were exercised in a standalone Chrome preview. Automation could not inspect the installed extension dashboard or complete its file-picker import flow.
- Renko execution can retain two checked price-mode controls in the source. The app warns and preserves both values.
- Rule names do not imply capture of their hidden numeric definitions.
- Charts are static SVG snapshots. Hover data and underlying price series are absent.
- Formatting improves presentation only. It never silently changes source signs, missing metrics, or original JSON values.
- Large libraries and unusually large reports can exhaust browser memory or storage. Individual import files are limited to 100 MB.
- Browser-local storage is not synchronized and is not a backup.
- Strategy rankings are provisional reported-result comparisons. Costs, dividends, leverage, cash flows, historical universe membership and valuation frequency are unverified. Missing CAGR is not substituted; zero drawdown does not produce infinite Calmar.
- Nifty history requires local CSV import. No actual index data is bundled. Missing edges and sparse series constrain benchmark comparisons; see [the method](INTELLIGENCE.md).
- No combined-portfolio return/drawdown, risk-adjusted alpha, significance test or future-performance prediction is calculated from summary metrics.
- Responsive and keyboard checks do not establish full WCAG compliance. Screen-reader, real-device touch, 200% text enlargement, and print-device testing still need broader validation.
