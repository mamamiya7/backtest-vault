Your research, in your browser.

Chrome extension for Windows and Linux. No developer tools, Python, Node.js, or separate server to install.

Already using Vault?

Use Update.cmd on Windows, or bash update.sh on Linux. Choose the same folder that Chrome currently loads (usually your original dist folder). Then click Reload on the existing extension and refresh RZone and Vault.

Back up your library first. Keep the extension installed: removing it or loading a new folder can create a separate, empty archive. Your saved runs stay in your Chrome profile; setup does not move them.

1

Extract everything

Extract the complete ZIP. Open the BacktestVault folder inside it. Keep all its files together.

2

Run setup

Windows: double-click Setup.cmd.
Linux: open a terminal here and run bash setup.sh.

Setup prints the permanent extension folder to use next.

3

Add to Chrome

Enter chrome://extensions in Chrome. Turn on Developer mode, click Load unpacked, and select the folder printed by setup.

The folder Chrome needs

Select the folder containing manifest.json. Setup uses these locations by default:

Windows%LOCALAPPDATA%\BacktestVault\extension

Paste this into the folder picker's address bar.

Linux~/.local/share/backtest-vault/extension

If you have set XDG_DATA_HOME, setup uses that location instead.

Pin Definedge Backtest Vault from Chrome's puzzle-piece menu. Open RZone, sign in, and refresh its page. Click the Vault toolbar icon → New test. Set up and run your backtests there.

Prefer to install without running a script?

Keep the extracted folder in a permanent location. In Chrome's Load unpacked picker, select its extension folder. Nothing else needs to run. Do not delete or move that folder afterward.

For future updates, close Vault/RZone tabs after saving pending work. Copy the new package's extension files into that same folder, replacing those files. Reload the existing extension, then reopen RZone and Vault. Never remove the extension to update it.

Setup is blocked or reports an error

Windows setup uses built-in commands and does not run PowerShell scripts or download executables. It does not change security policies. If your organization blocks scripts or unpacked extensions, ask its administrator for an approved installation. Do not disable protection.

For a missing manifest, select the extension folder, not the ZIP or its parent. For a copy error, use a writable folder owned by you and keep the full package extracted. Setup retains a backup location if replacement fails; follow its printed recovery instructions.

Updates and backups

Use a complete Vault release for every update. Updates are deliberate; setup does not fetch new versions automatically. Choose Back up all on Vault's library page to keep an independent JSON copy of your research.

Windows and Linux use the same package. Saved backups can be imported on another computer; browser storage does not automatically follow the installation folder.
